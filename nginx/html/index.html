Privacy boundary

What this repo is designed to keep hidden

YaCy fetches leave through Privoxy and Tor. nginx does not publish plaintext ports, and the repo excludes runtime data, TLS keys, and bridge credentials.

If you want more apps behind this same origin later, add them as separate proxy locations in nginx/default.conf.
